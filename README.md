# Provenio — OSINT-инструмент с доказательной базой

Provenio — локальная платформа для OSINT-расследований: собирает публичные источники в кейсы, архивирует их с хэшами, вытаскивает сущности, строит граф связей и оценивает достоверность фактов. Всё работает на вашей машине, данные никуда не отправляются.

> ⚠️ Используйте только для публичных данных и в рамках закона. Инструмент рассчитан на пассивный сбор информации и защитные проверки: в нём нет перебора паролей, эксплойтов и сканирования портов чужих систем.

## Возможности

### Кейсы и доказательства
- **Кейсы и источники**: добавляете URL, Provenio сохраняет снимок HTML, SHA-256, время и HTTP-статус.
- **Автоизвлечение сущностей**: email, телефоны, домены, IP-адреса, аккаунты соцсетей.
- **Граф связей** «источник — сущность».
- **Оценка достоверности факта** (0–100): учитывает число независимых доменов и надёжность каждого источника (1–5). Один домен засчитывается один раз.
- **Журнал аудита с хэш-цепочкой**: изменить историю незаметно нельзя.
- **Проверка целостности снимков** и **экспорт HTML-отчёта** по кейсу.

### Инструменты (`provenio_tools.py`)

| Группа | Инструменты |
|---|---|
| Домен и сеть | DNS, обратный DNS, информация об IP, WHOIS, RDAP, SSL-сертификат, HTTP-заголовки, поддомены (crt.sh), Wayback Machine, reverse IP |
| Разведка сайта | полный обзор сайта, robots.txt и sitemap, определение технологий, цепочка редиректов, безопасность почты (SPF, DMARC, DKIM, MX), security.txt, хэш favicon |
| OSINT по людям | поиск по username, разбор email, информация о номере телефона |
| Защита | проверка пароля по утечкам HaveIBeenPwned через k-anonymity (сам пароль не покидает компьютер), оценка стойкости пароля |
| Утилиты | хэши и определение типа хэша, декодер JWT, CIDR-калькулятор, timestamp, UUID, IDN/punycode, энтропия Шеннона, проверка Луна, перевод систем счисления, конструктор Google-дорков, кодирование и декодирование (base64, hex, URL, ROT13, binary) |

## Установка и запуск

Нужен **Python 3.9+**. Сторонние пакеты не требуются: используется только стандартная библиотека.

```bash
git clone https://github.com/nzikach/Provenio-OSINT-Tool.git
cd Provenio-OSINT-Tool
```

**Современный интерфейс** (рекомендуется) — откроется в браузере:

```bash
python provenio_ui.py
```

Чтобы интерфейс открывался в отдельном окне, а не во вкладке браузера, установите pywebview:

```bash
pip install pywebview
```

**Классический интерфейс** на tkinter (только кейсы и доказательства, без набора инструментов):

```bash
python provenio.py
```

## Структура проекта

| Файл | Назначение |
|---|---|
| `provenio.py` | ядро: база кейсов (SQLite), архивация, извлечение сущностей, достоверность, аудит, отчёты, tkinter-интерфейс |
| `provenio_tools.py` | набор OSINT- и ИБ-инструментов, каждый возвращает `dict` |
| `provenio_ui.py` | локальный веб-интерфейс поверх ядра и инструментов |
| `provenio_data/` | создаётся при первом запуске: база `provenio.db` и снимки страниц (не попадает в git) |

## Безопасность

- Веб-интерфейс слушает только `127.0.0.1` на случайном порту и защищён одноразовым токеном, который генерируется при каждом запуске.
- Данные кейсов хранятся локально в `provenio_data/` и исключены из репозитория через `.gitignore`.
- Часть инструментов обращается к публичным сервисам: crt.sh, ip-api.com, archive.org, HackerTarget, HaveIBeenPwned (только первые 5 символов SHA-1 хэша пароля).
