# Provenio — OSINT-платформа с доказательной базой

Provenio — локальное приложение для OSINT-расследований под Windows. Оно собирает публичные источники в кейсы и архивирует их с хэшами. Результаты 50+ инструментов сохраняются как доказательства. Provenio строит граф связей с пивотами, как в Maltego, ведёт хронологию, следит за изменениями страниц и выгружает проверяемый пакет доказательств. Всё работает на вашем компьютере.

> ⚠️ Только для публичных данных и в рамках закона. Provenio рассчитан на пассивный сбор информации и защитные проверки. В нём нет перебора паролей, эксплойтов, сканирования портов чужих систем и трюков с формами восстановления пароля.

## Быстрый старт

**Готовая программа.** Скачайте `Provenio.exe` в разделе [Releases](https://github.com/nzikach/Provenio-OSINT-Tool/releases) и запустите. Python и установка не нужны.

- Нужна Windows 10/11 со средой Microsoft Edge WebView2 (в Windows 11 она уже есть).
- Программа без цифровой подписи. При первом запуске SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае». Контрольная сумма SHA-256 лежит рядом с exe в релизе.
- Отдельные антивирусы иногда ложно срабатывают на программы, собранные PyInstaller. Чтобы этого было меньше, релизы собираются с собственным загрузчиком, скомпилированным из исходников. Исходный код открыт, exe можно собрать самому через `build.ps1`.

**Из исходников** (Python 3.9+):

```bash
git clone https://github.com/nzikach/Provenio-OSINT-Tool.git
cd Provenio-OSINT-Tool
pip install pywebview        # необязательно: отдельное окно вместо вкладки браузера
python provenio_ui.py
```

**Собрать exe самому:**

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт создаёт `.venv`, ставит зависимости, прогоняет тесты и собирает `dist\Provenio.exe`. Автосборка на GitHub делает то же самое при каждом пуше, а при теге `v*` выпускает релиз с exe.

## Возможности

### Кейсы и доказательства
- **Архивация источников**: снимок HTML, SHA-256, время и HTTP-статус.
- **Любой результат инструмента — в кейс** одной кнопкой: JSON-снимок с SHA-256, запись в журнале аудита, найденные сущности сразу появляются в графе.
- **Сущности**: email, телефоны, домены, IP, аккаунты соцсетей. Извлекаются из страниц и из результатов инструментов.
- **Достоверность факта** (0–100%): по числу независимых источников и их надёжности (1–5).
- **Журнал аудита с хэш-цепочкой**: изменить историю незаметно нельзя.

### Собственные функции Provenio
| Функция | Что даёт |
|---|---|
| **Пивоты в графе** | Клик по узлу (домен, IP, email, аккаунт) показывает подходящие инструменты. Результат автоматически добавляется в кейс и в граф. |
| **Хронология кейса** | Даты из всех источников на одной ленте: архивация, публикации, регистрация доменов, сертификаты, снимки Wayback, создание аккаунтов. |
| **Мониторинг изменений** | Страница переснимается по расписанию (от 15 минут до суток). Если видимый текст изменился, сохраняется новая версия и приходит уведомление. Работает, пока Provenio открыт. |
| **Сравнение снимков** | Построчно показывает, что удалено и что добавлено между версиями страницы или любыми двумя источниками. |
| **Пакет доказательств** | ZIP со снимками, отчётом, полным журналом аудита и манифестом хэшей. Встроенная проверка пересчитывает всё и показывает, не подменено ли что-то. |
| **Связанные сайты по ID счётчиков** | ID Google Analytics/AdSense/GTM, Яндекс Метрики, Pixel, верификаций и хэш favicon. Общие ID на разных сайтах означают одного владельца. |
| **Хронология домена** | Регистрация, первый SSL-сертификат, первый и последний снимок веб-архива, возраст домена. |

| Инструмент | Похож на | Что делает |

| URL из веб-архива | gau, waymore | все известные архиву адреса, сгруппированные: конфиги, бэкапы, документы, API, админки |
| Поиск утёкших ключей | gitleaks | 20+ правил (AWS, GitHub, Slack, Stripe, Telegram-боты, приватные ключи…) в странице и её JS; значения маскируются |

| Извлечение IOC | iocextract | URL, IP, домены, хэши, CVE, BTC/ETH, техники ATT&CK; понимает `hxxp` и `[.]` |

| CVE | cve-search | NVD + CISA KEV (эксплуатируется ли) + EPSS (вероятность атаки) |

**Остальные инструменты:**

| Группа | Инструменты |
|---|---|
| Сеть и домены | DNS, обратный DNS, гео и ASN по IP, WHOIS, RDAP, TLS-сертификат, заголовки безопасности, поддомены, Wayback, reverse IP |
| Организация | ASN и сети (RIPEstat), поиск AS по названию компании |
| Разведка сайта | полная разведка, технологии, robots/sitemap, редиректы, favicon-хэш, SPF/DMARC/DKIM, security.txt |
| Угрозы | репутация IOC (AlienVault OTX, urlscan.io, DNSBL; с ключами — VirusTotal, AbuseIPDB), порты и CVE без сканирования (Shodan InternetDB) |
| Люди | разбор email и телефона, публичный Telegram-канал, BTC/ETH-адреса, обратный поиск фото |
| Защита | пароль в утечках (HIBP k-anonymity, пароль не покидает компьютер), стойкость пароля |

У долгих инструментов есть **прогресс-бар и кнопка остановки**. **Пакетный режим** запускает один инструмент по списку значений.

### Экспорт
Отчёт HTML, весь кейс в JSON, сущности в CSV (открывается в Excel), пакет доказательств в ZIP.

## Настройки
**⚙ Настройки** в левой панели:
- **прокси** для всех запросов;
- **таймаут** запросов;
- необязательные **ключи API**: Shodan, VirusTotal, AbuseIPDB, urlscan, AlienVault OTX, GitHub.

Без ключей работают все бесплатные источники. Ключи хранятся только на вашем компьютере и шифруются Windows DPAPI: расшифровать их может только ваша учётная запись.

## Где хранятся данные
`%LOCALAPPDATA%\Provenio`: база `provenio.db`, снимки `snapshots\`, настройки, журнал `provenio.log`. Открыть папку можно кнопкой **📁 Папка данных**.

Данные версии 1.x (папка `provenio_data` рядом со скриптом) копируются туда автоматически при первом запуске. Старая папка остаётся нетронутой. Другой путь можно задать переменной окружения `PROVENIO_DATA`.

## Безопасность
- Интерфейс доступен только с вашего компьютера (`127.0.0.1`, случайный порт) и защищён одноразовым токеном.
- Сохранённые снимки страниц открываются в песочнице (CSP `sandbox`): их скрипты не выполняются.
- Если у сайта неполная цепочка сертификатов, страница всё равно архивируется, но в статусе честно помечается «TLS не проверен».
- Внешние сервисы, к которым обращаются инструменты: crt.sh, archive.org, ip-api.com, RIPEstat, HackerTarget, Shodan InternetDB, AlienVault OTX, urlscan.io, NVD, FIRST EPSS, CISA KEV, GitHub API, blockstream.info, Blockscout, macvendors.com, HaveIBeenPwned (только первые 5 символов SHA-1 пароля). Сервисы с ключами — только если вы их добавили.
