<h1 align="center">Provenio 3.0</h1>

Локальное приложение для OSINT-расследований. Собирает публичные источники в кейсы, сохраняет каждую страницу и каждый результат инструмента как доказательство с хэшем и меткой времени, строит граф связей и выгружает пакет, который можно проверить независимо. Данные остаются на вашем компьютере.

Только для публичных данных и в рамках закона.

## Установка

Файлы лежат в [Releases](https://github.com/nzikach/Provenio-OSINT-Tool/releases).

| Файл | Для чего |
|---|---|
| `Provenio-Setup-<версия>.exe` | установщик для Windows 10/11 |
| `Provenio-<версия>-portable.exe` | версия без установки |
| `SHA256SUMS.txt` | контрольные суммы |

Программа не подписана: если SmartScreen покажет предупреждение, нажмите «Подробнее» → «Выполнить в любом случае». На телефоне Provenio можно открыть и без установки: «Открыть на телефоне» в программе показывает QR-код для домашней сети.

## Что умеет

- Архивирует страницы: HTML, скриншот, PDF, SHA-256, метка времени RFC 3161.
- Запускает 60+ инструментов: домены, IP, email, ники, утечки, сертификаты, метаданные файлов. Результат сохраняется в кейс одной кнопкой.
- Извлекает сущности и строит граф связей с пивотами.
- Ведёт хронологию, следит за изменениями страниц, сравнивает версии.
- Закрепляет доказательства в блокчейне Bitcoin через OpenTimestamps.
- Выгружает отчёт, который сам проверяет свои хэши, и ZIP-пакет с журналом аудита.
- IP-радар, глобус, CT-поток, учебная XSS-лаборатория.

## Запуск из исходников

```bash
git clone https://github.com/nzikach/Provenio-OSINT-Tool.git
cd Provenio-OSINT-Tool
python provenio_ui.py
```

Нужен Python 3.9+. Сборка exe: `powershell -ExecutionPolicy Bypass -File build.ps1`. Тесты: `python -m unittest discover -s tests`.

## Данные и безопасность

- Данные хранятся в `%LOCALAPPDATA%\Provenio`. Аккаунт локальный, сервера нет.
- Интерфейс доступен только с `127.0.0.1`. Ключи API шифруются Windows DPAPI.
- Запросы к базе только параметризованные, снимки страниц открываются в песочнице.
