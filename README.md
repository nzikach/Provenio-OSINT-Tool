# Provenio — OSINT-платформа с доказательной базой

Provenio — локальное приложение для OSINT-расследований под Windows. Оно собирает публичные источники в кейсы и архивирует их с хэшами. Результаты 55+ инструментов сохраняются как доказательства, а страницы — вместе со скриншотом и меткой времени RFC 3161. Provenio строит граф связей с пивотами, как в Maltego, ведёт хронологию, следит за изменениями страниц и выгружает проверяемый пакет доказательств. Всё работает на вашем компьютере.

> ⚠️ Только для публичных данных и в рамках закона. Provenio рассчитан на пассивный сбор информации и защитные проверки. В нём нет перебора паролей, эксплойтов, сканирования портов чужих систем и трюков с формами восстановления пароля.

## Быстрый старт

**Готовая программа.** В разделе [Releases](https://github.com/nzikach/Provenio-OSINT-Tool/releases) у каждой версии есть свои файлы:

| Файл | Что это |
|---|---|
| `Provenio-Setup-<версия>.exe` | **установщик** (рекомендуется): ставит программу без прав администратора, добавляет её в меню «Пуск» и в «Приложения» Windows для удаления |
| `Provenio-<версия>-portable.exe` | одна программа без установки, например для флешки |
| `Provenio-<версия>.ipa` | приложение для iPhone/iPad (см. ниже) |
| `SHA256SUMS.txt` | контрольные суммы всех файлов |

При первом запуске создайте **локальный аккаунт**: имя пользователя и пароль (подробнее — в разделе «Аккаунт и документы»). Python не нужен.

- Нужна Windows 10/11 со средой Microsoft Edge WebView2 (в Windows 11 она уже есть).
- Программа без цифровой подписи. При первом запуске SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае». Контрольные суммы SHA-256 лежат в `SHA256SUMS.txt` в релизе.
- Отдельные антивирусы иногда ложно срабатывают на программы, собранные PyInstaller. Чтобы этого было меньше, релизы собираются с собственным загрузчиком, скомпилированным из исходников. Исходный код открыт, exe можно собрать самому через `build.ps1`.

**iPhone / iPad.** В том же разделе Releases лежит `Provenio-<версия>.ipa`. Это то же приложение: ядро Provenio работает прямо на телефоне, интерфейс адаптирован под экран и касания (глобус и граф — пальцем, щипок для масштаба). IPA не подписан: Apple не разрешает ставить такие файлы напрямую, поэтому установите его одним из способов:

| Способ | Что нужно | Срок работы |
|---|---|---|
| [AltStore](https://altstore.io) или [SideStore](https://sidestore.io) | компьютер (AltServer) или SideStore на телефоне, бесплатный Apple ID | 7 дней, продлевается в один тап |
| [Sideloadly](https://sideloadly.io) | компьютер Windows/macOS, бесплатный Apple ID | 7 дней, затем переустановить |
| [TrollStore](https://github.com/opa334/TrollStore) | поддерживаемая версия iOS | бессрочно |
| Платный аккаунт разработчика Apple ($99/год) | подпись своим сертификатом | 1 год |

Порядок для AltStore/Sideloadly: скачайте `Provenio-<версия>.ipa` → откройте его в AltStore («My Apps» → «+») или перетащите в Sideloadly → войдите своим Apple ID → на iPhone: «Настройки» → «Основные» → «VPN и управление устройством» → доверьте профилю разработчика. На iOS 16+ включите «Режим разработчика» («Настройки» → «Конфиденциальность и безопасность»).

На iPhone экспорт (пакет доказательств, CSV, граф) сохраняется в «Файлы» → «На iPhone» → Provenio, отчёт открывается прямо в приложении. Недоступно на iPhone: скриншоты и PDF страниц (нужен Edge) и ИИ-сводка.

**Из исходников** (Python 3.9+):

```bash
git clone https://github.com/nzikach/Provenio-OSINT-Tool.git
cd Provenio-OSINT-Tool
pip install pywebview        # необязательно: отдельное окно вместо вкладки браузера
pip install anthropic        # необязательно: ИИ-сводка кейса (Claude)
python provenio_ui.py
```

**Собрать exe самому:**

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт создаёт `.venv`, ставит зависимости, прогоняет тесты и собирает `dist\Provenio.exe`. Установщик собирается из `installer\Provenio.iss` в [Inno Setup 6](https://jrsoftware.org/isinfo.php): `ISCC /DAppVersion=2.2.0 installer\Provenio.iss`. Автосборка на GitHub при каждом пуше делает всё это и проверяет зависимости через `pip-audit`. При теге `v*` она выпускает релиз с установщиком, портативной версией, IPA и контрольными суммами.

## Возможности

### Кейсы и доказательства
- **Архивация источников**: снимок HTML, скриншот страницы (и PDF по желанию) через Edge без окна, SHA-256 каждого файла, время и HTTP-статус.
- **Обход ссылок**: архивировать страницы, на которые ссылается источник, на глубину 1–2 (с пометкой, где каждая найдена).
- **Любой результат инструмента — в кейс** одной кнопкой: JSON-снимок с SHA-256, запись в журнале аудита, найденные сущности сразу появляются в графе.
- **Сущности**: email, телефоны, домены, IP, аккаунты соцсетей. Извлекаются из страниц и из результатов инструментов.
- **Достоверность факта** (0–100%): по числу независимых источников и их надёжности (1–5).
- **Журнал аудита с хэш-цепочкой**: изменить историю незаметно нельзя.

| 🔐 **Самопроверяющийся отчёт** | Один HTML-файл для суда, журналиста или заказчика. Открытый в любом браузере, он сам пересчитывает SHA-256 всех вложенных снимков и цепочку журнала аудита. Изменение одной буквы показывает «цепочка нарушена» |
| 🧬 **Один оператор** | Список доменов раскладывается на кластеры «один хозяин». Признаки: общие ID аналитики и верификаций, один сертификат, favicon, IP (CDN не в счёт), NS/MX (массовые провайдеры не в счёт), регистратор и дата, похожесть вёрстки (simhash). У каждой связи есть объяснение |
| 🧩 **Геопазл** | На глобусе. Описываете, что видно на фото («церковь, в 200 м река, в 400 м мост»), и получаете все такие места в городе из OpenStreetMap с переходом на панорамы и спутник |
| ⚖ **Матрица конкурирующих гипотез** | Метод ACH: побеждает версия, которой меньше всего противоречат улики. Надёжность улик берётся из источников кейса. Отмечаются улики, которые ничего не различают, и улики, на которых держится вывод |
| 🛡 **Ваш цифровой след** | Самоаудит организации: почта (SPF/DMARC), заголовки сайта, сертификат, служебные поддомены, открытые порты и CVE, утечки, конфиги и админки в веб-архиве, авторы в метаданных опубликованных документов. Итог — оценка 0–100 и чек-лист «что закрыть» |
| 🕰 **Ритм жизни** | По активности на GitHub, Reddit, Bluesky, Mastodon или по своим временным меткам строится тепловая карта «день × час». Из неё выводятся часовой пояс, режим сна, будни и выходные, а также недели со сдвигом режима (поездка или другой человек за аккаунтом) |

Миниатюра EXIF против самого фото: показывает обрезку и правки после съёмки. Также оценка качества JPEG по таблицам квантования, следы Photoshop/GIMP/генераторов, XMP-история, C2PA |
| ☀ **Хронолокация по тени** | На глобусе. Высота объекта и длина тени дают окружность всех мест, где солнце стоит под таким углом в это время. Направление тени сужает её до участка. Обратная задача: в какое время снят кадр в известном месте |
| 📨 **Разбор email-заголовков** | Путь письма по серверам с геолокацией и линией на глобусе, задержки и TLS по хопам, SPF/DKIM/DMARC, выравнивание доменов, подмена Reply-To и Return-Path, спрятанный адрес в имени отправителя |

| 🔴 **CT-поток** | Живое чтение журналов Certificate Transparency Let's Encrypt (~35 сертификатов в секунду). Мгновенное уведомление, если выпущен сертификат на домен-двойник бренда (вхождение, опечатка в 1 символ, 0→o, 1→l). Можно держать в фоне. Трафик ~90 МБ/ч, пока поток включён |

### Новое в 2.3 — XSS-лаборатория

Вкладка **🧪 XSS-лаб**: 14 намеренно уязвимых учебных сайтов, разбитых на 5 уровней сложности. В каждом есть сюжет, 3 подсказки, готовое решение (открывается по запросу) и разбор «как исправить». Цель везде одна: выполнить `alert()`, `confirm()`, `prompt()` или `print()` в контексте сайта. Решение засчитывается автоматически.

| Уровень | Лабы |
|---|---|
| ●○○○○ Новичок | отражённая XSS в HTML · хранимая XSS в гостевой книге |
| ●●○○○ Ученик | выход из атрибута `value` · DOM XSS через `location.hash` |
| ●●●○○ Практик | строка JavaScript с «экранированным» апострофом · фильтр `javascript:` в один проход · `</script>` внутри JSON |
| ●●●●○ Эксперт | HTML-сущности внутри `onclick` · обход WAF с чёрным списком · обход санитайзера на регулярках · `postMessage` без проверки origin + свой exploit-сервер |
| ●●●●● Безумие | побег из песочницы клиентских шаблонов (Proxy + чёрный список) · обход строгого CSP через JSONP · DOM clobbering сквозь allowlist-санитайзер |

Лабы работают на отдельном локальном сервере (свой порт, а значит другой origin) внутри `iframe sandbox`. Код из лабы не может обратиться к Provenio, его токенам и вашим данным. Подделать решение с exploit-сервера тоже нельзя: ключ подтверждения есть только на страницах-жертвах.

| **Сравнение снимков** | Построчно показывает, что удалено и что добавлено между версиями страницы или любыми двумя источниками. |

| **Хронология домена** | Регистрация, первый SSL-сертификат, первый и последний снимок веб-архива, возраст домена. |

## Аккаунт и документы
- **Регистрация** при первом запуске: имя пользователя, пароль (от 8 символов, есть индикатор надёжности), дата рождения для проверки возраста. Ещё нужно отдельно согласиться с условиями использования и с политикой конфиденциальности. Ни одна галочка не стоит заранее, проверка обновлений тоже включается только вашей галочкой.
- Аккаунт **локальный**, один на папку данных. Сервера нет, email не нужен, писем и рассылок нет.
- **Пароль** хранится только как хэш scrypt со случайной солью. После 5 неверных попыток вход временно блокируется. **Дата рождения не сохраняется**: записывается только отметка о проверке.
- **Отмена в один шаг.** Кнопка «Выйти» на боковой панели. «Удалить аккаунт» в настройках стирает всё: аккаунт, кейсы, снимки, ключи и настройки (нужны пароль и слово УДАЛИТЬ). Программу можно удалить через «Приложения» Windows, деинсталлятор отдельно спросит про данные, по умолчанию они сохраняются.
- **Бесплатно**: нет подписок, платных функций и скрытых платежей. Платные API сторонних сервисов вы оплачиваете им напрямую.
- Документы: [Условия использования](legal/TERMS.md) · [Политика конфиденциальности](legal/PRIVACY.md) · [Возврат и отмена](legal/REFUND.md) · [Сторонние сервисы и SDK](legal/THIRD_PARTY.md). Они же открываются в программе: «📄 Условия и конфиденциальность».
- **Забыли пароль?** Сбросить его письмом нельзя. Закройте Provenio и удалите `account.json` в папке данных, затем создайте аккаунт заново. Кейсы останутся. Пароль защищает вход в программу, а саму папку данных защищает ваша учётная запись Windows.

## Где хранятся данные
`%LOCALAPPDATA%\Provenio`: база `provenio.db`, снимки `snapshots\`, аккаунт `account.json`, настройки, журнал `provenio.log`. Открыть папку можно кнопкой **📁 Папка данных**.

Данные версии 1.x (папка `provenio_data` рядом со скриптом) копируются туда автоматически при первом запуске. Старая папка остаётся нетронутой. Другой путь можно задать переменной окружения `PROVENIO_DATA`.

**Портативный режим:** положите рядом с `Provenio.exe` пустой файл `portable.txt` (или нажмите кнопку в настройках) — данные будут храниться в папке `ProvenioData` рядом с программой. Ключи API зашифрованы для учётной записи Windows, на другом компьютере их нужно ввести заново.

## Безопасность
- Интерфейс доступен только с вашего компьютера (`127.0.0.1`, случайный порт). До входа токен страницы открывает только вход, регистрацию и документы. После входа выдаётся отдельный токен сеанса, а после выхода он перестаёт действовать.
- **Защита от SQL-инъекций.** Все запросы к базе параметризованы, а соединение `SafeConnection` проверяет это на каждом вызове:
  - в тексте SQL запрещены строковые литералы, комментарии и `;`. Значения пользователя попадают только в параметры, поэтому не работают классические, UNION-, boolean-, time-based и second-order инъекции;
  - несколько команд за один вызов (stacked queries) не выполняются;
  - число `?` должно совпадать с числом параметров, а сами параметры могут быть только строками, числами или байтами;
  - авторизатор SQLite запрещает `ATTACH`/`DETACH`, `PRAGMA`, `DROP`, `load_extension` и другие опасные функции. Включён defensive mode, `trusted_schema` выключен;
  - номера кейсов и записей из запросов интерфейса проверяются как целые числа.

  Всё это покрыто тестами с набором типовых инъекций.
- Ключи API зашифрованы (DPAPI), в интерфейсе видны только последние 4 символа. Из ответов интерфейса, ошибок и сохранённых в кейс результатов они вырезаются.
- Сторонние пакеты проверяются через `pip-audit` при каждой сборке. Аудит SDK лежит в [legal/THIRD_PARTY.md](legal/THIRD_PARTY.md): телеметрии, аналитики и рекламных SDK в программе нет.
- Сохранённые снимки страниц открываются в песочнице (CSP `sandbox`): их скрипты не выполняются.
- Если у сайта неполная цепочка сертификатов, страница всё равно архивируется, но в статусе честно помечается «TLS не проверен».
- Внешние сервисы, к которым обращаются инструменты: crt.sh, archive.org, ip-api.com, RIPEstat, HackerTarget, Shodan InternetDB, AlienVault OTX, urlscan.io, NVD, FIRST EPSS, CISA KEV, GitHub API, blockstream.info, Blockscout, macvendors.com, HaveIBeenPwned (только первые 5 символов SHA-1 пароля), XposedOrNot, StopForumSpam, открытые списки угроз (FireHOL, Spamhaus, IPsum, abuse.ch и др.), OpenSky Network, airplanes.live, CelesTrak, USGS, NASA EONET, OpenStreetMap Nominatim, службы меток времени RFC 3161, GitHub (проверка обновлений). Сервисы с ключами — только если вы их добавили. ИИ-сводка отправляет данные кейса в Anthropic API только по вашей команде.
